# San Francisco Crime Classification

Project Overview
This project focuses on classifying crime incidents in San Francisco using historical crime data and machine learning classification techniques. The goal is to identify patterns in crime data and predict the category of crime based on available features.

Objectives
- Analyze and preprocess real-world crime data  
- Build a classification model to predict crime categories  
- Evaluate model performance using standard classification metrics  

Dataset
The project uses the **San Francisco Crime Dataset**, which contains records of crime incidents with attributes such as date, time, location, and incident details.

**Note:**  
Due to GitHub file size limits, the dataset files are not included in this repository.

You can download the dataset from:
- https://www.kaggle.com/c/sf-crime
